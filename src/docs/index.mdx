Welcome to the documentation! This site is built with **Astro** and uses **daisyUI** for beautiful, themeable styling.

## Features

- 🚀 **Fast & Modern** - Built with Astro for optimal performance
- 🎨 **35+ Themes** - Switch between light and dark themes using daisyUI
- 📱 **Responsive** - Works great on all devices
- 📝 **MDX Support** - Write content with MDX for interactive components
- 📚 **Easy Navigation** - Auto-generated sidebar and table of contents

## Quick Start

Get started by exploring the documentation sections in the sidebar. Here are some recommended starting points:

1. [Installation Guide](/astro_2/getting-started/installation) - Set up your development environment
2. [Configuration](/astro_2/getting-started/configuration) - Learn how to configure the site
3. [Example Guide](/astro_2/guides/example) - See example content and features

## Theme Switcher

Click the theme button in the top right corner to switch between different themes. Your preference is saved automatically!
